Second Brain Bridge 機能マニュアル

どのボタンをいつ使うか

📋

URLから取り込む

X・note・ブログ・一般Webを本文ごとRAW保存。

Xで共有 → リンクコピー → Bridge
📄

PDFを入れる

文字入りPDFの本文を抽出して保存。

Capture → 資料を読み込む
✍️

頭から出す

授業後の気づき、メモ、AI相談の結論を数行で保存。

迷ったらRAWのままでOK
💬

履歴を資産化

ChatGPT / Claude / Codex / Project履歴を保存。

原文を残し後でDecision等へ
📦

過去履歴を一括移行

ChatGPT / ClaudeのエクスポートZIP・JSONをまとめて処理。

1チャットずつ探さない
🔎

Brainに聞く

X・Web・PDF・AIチャット・授業・Projectを横断検索。

ChatGPT用文脈を生成
🌱

Brainを育てる

RAWからWiki・Insight・Skill候補を作る整理指示を生成。

重要方針は自動確定しない
🛠️

初心者向け手順＋完成指示書を自動生成。

用途を選ぶ → コピー → Codex
✏️

編集・分類・削除

保存後にタイトル、本文、分類を修正。個別削除も可能。

よく使う4つの実践フロー

迷ったらこの通り

① Xで発見 → ② Bridgeで本文保存 → ③ ChatGPTで今日すぐ検討 → ④ 採用案・学びをBrainへ戻す

① 授業後1〜3行メモ → ② BridgeへPractice候補 → ③ ChatGPTで複数回分を分析 → ④ 次の授業で再実践 → ⑤ 結果を戻す

① ChatGPTで課題・仕様・MVP → ② BridgeにDecision保存 → ③ Codexで実装・テスト → ④ GitHubを現行正本 → ⑤ 失敗・改善・SkillをBrainへ

① ChatGPT履歴をExport → ② Codexで一括整理 → ③ Obsidianへ長期保存 → ④ Bridgeで横断検索 → ⑤ ChatGPTで過去知識を使って相談

🛡️ Brainを壊さない4原則
  1. RAW原典は原則削除・上書きしない。
  2. 重要方針は維持・修正・廃止・保留で差分管理。
  3. 明示採択していない提案をDecisionとして自動確定しない。
  4. 不確実な変更はAI-Proposalsへ。
07

迷った時の超シンプル判定

どれを使う？を5秒で

Obsidianは毎日開くの？

毎日開かなくてOK。Bridgeで取り込み、Codexで整理し、必要な時だけ確認する裏側の記憶庫です。

Claudeを解約しても大丈夫？

大丈夫です。ChatGPT + Codex + Obsidian + Bridgeで成立します。

Vaultが育つまで創造に使えない？

いいえ。今日保存した1件からすぐ使えます。

一番簡単な覚え方は？

ChatGPT = 考える / Codex = やる / Obsidian = 覚える / Bridge = つなぐ

探す時間を、創る時間に。

読んだこと、考えたこと、作ったこと、失敗したこと。すべてを「次の自分」が使える形で残していく。

入れる → 使う → 作る → 戻す → Brainが育つ
