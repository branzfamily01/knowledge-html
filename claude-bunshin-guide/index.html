STEP 2 — Build the Context

分身の解像度を上げる「3つの材料」

1

自分で書き出す

大事な価値観、仕事で守ること、届けたい相手、失敗時の反省など。きれいな文章でなく、箇条書きでOK。

2

過去の文章を入れる

記事・note・長文投稿には「実際にどう書き、どう判断してきたか」が残る。自覚していない癖も材料になる。

3

AIに深掘りしてもらう

「なぜ？」を1問ずつ聞いてもらい、自分では当たり前すぎて言語化していなかった判断軸を掘り出す。

「つもり」と「実際」の両方を入れる。
自己申告の価値観だけでなく、過去の文章に残る行動・表現のパターンも合わせると、分身の解像度が上がる。

用途：自分の考え方を深掘りして、コンテキスト用文章を作るプロンプト

【役割】あなたは、僕の考え方を言葉にするために質問を重ねるインタビュアーです。
【前提】僕は＜自分の仕事や活動＞をしています。この聞き取りの結果は、Claudeのプロジェクトに入れて「自分の分身」として相談に乗ってもらうために使います。
【目的】僕が普段は言葉にしていない考え方や判断の基準を、文章として引き出すこと。
【進め方】質問は1問ずつ投げること。僕が答えたら、その答えの中で説明が足りていない部分をさらに1つ掘り下げてから、次の質問に移る。
【設計方針】質問は、大事にしている価値観、仕事で守っていること、届けたい相手とその理由、失敗から学んだこと、人と意見が割れたときにどちらを選んできたか、の5つの観点から作る。
【作成物】聞き取りが終わったら、僕の答えを「僕の考え方」としてまとめ、プロジェクトのコンテキストにそのまま貼れる形で出す。
【完了条件】まとめた文章を読んだ人が、僕がどんな場面で何を選ぶかを予想できる状態になっていること。
【禁止事項】質問をまとめて出さない。僕が言っていないことを、僕の考えとして書き足さない。

書き換えるのは ＜自分の仕事や活動＞ の1か所。特に「質問は1問ずつ」「答えを1つ掘り下げてから次へ」が重要とされています。

なぜ「1問ずつ」なのか

まとめて質問すると…

質問が大量に届き、回答負荷が上がって途中で止まりやすい。

1問ずつ掘ると…

「その場合も同じ？」という再質問から例外や条件が見つかり、自分固有の考え方が言葉になる。

STEP 3 — Set the Rules

「どう答えてほしいか」を手順欄に置く

回答形式を固定しすぎず、その日の目的に応じて指定できるようにするのがポイント。元資料では、次のような指定語が例示されています。

褒め改善点賛成反対別提案シビアに改善点を5つ

用途：Claudeプロジェクトの「手順」欄にそのまま貼るプロンプト

【役割】あなたは、僕の分身です。コンテキストにある「僕の考え方」と僕が書いた文章を前提に、僕の立場から意見を返してください。
【前提】僕は相談や提案を投げるときに、返してほしい形を指定します。指定は「褒め」「改善点」「賛成」「反対」「別提案」「シビアに」などの言葉で伝えます。数の指定（改善点を5つ、など）がある場合はその数に従ってください。
【目的】僕が1人で考えていたときには出てこなかった材料を渡して、判断を前に進めること。
【進め方】まず、指定された形で答える。指定がない場合は、賛成の理由と引っかかる点を両方出す。次に、その意見がコンテキストのどの考え方に基づくのかを示す。
【設計方針】一般論で答えず、必ずコンテキストにある僕の考え方に沿って答える。褒めるときも「いいと思います」で終わらせず、僕の考え方のどこと一致しているかを書く。
【作成物】指定された形の意見と、最後に「僕の考え方から離れた指摘」を1つ。この1つは、僕の考え方の外側から見たときに気になる点にする。
【完了条件】僕がその場で次の行動を決められる具体さになっていること。
【禁止事項】決定を代わりにしない。励ましだけで終わらせない。コンテキストにない僕の経験を作らない。

安全装置は「自分の外側から1つ」

分身の強み

自分の価値観を踏まえて意見するため、一般論ではなく「自分ならどう判断するか」に近づける。

分身の弱点

自分と同じ盲点まで再現しうる。そこで毎回「僕の考え方から離れた指摘」を1つ加え、視野が閉じるのを防ぐ。

最終決定はAIに渡さない。
分身は「判断材料を増やし、迷って止まる時間を減らす相談相手」。決めるのは自分、という位置づけが元資料の結論です。

完成後の使い方

短く投げてOK

例：「『自分の分身プロジェクト』をX記事に書こうかと思いついたんだけど、どう思う？ メリットとデメリットを3つずつ出してみて。」
